Unitas

Browser, editor, and PDF / MD / HTML viewer in one tabbed window.

Vimium-style keys. NORMAL: keys control the app. INSERT (in a text field, or after i): keys go to the page. Esc goes back. No Ctrl shortcuts. Press ? for every key.

o / O / TVomnibar: open URL, history, search / in a new tab / open tabs
:Command line: :w save, :q close tab, :e open file, :settings

f / F / yfLink hints: open / open in new tab / copy URL
/ n NFind / next / previous
v / VVisual mode / line mode (y copies)
J K · t x XNext / previous tab · new / close / restore tab
